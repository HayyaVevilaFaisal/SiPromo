# Font laporan PDF

Isi laporan memakai Cambria dan Cambria Bold, sesuai font isi pada PDF referensi UNPAR yang diberikan pengguna. File font disertakan dan didaftarkan melalui PDFKit agar hasil tidak bergantung pada font yang terpasang pada server atau perangkat pembaca.

Sumber font: instalasi Microsoft Word lokal (`Contents/Resources/DFonts/Cambria.ttc` dan `Cambriab.ttf`). Koleksi TTC juga memuat Cambria Math; generator secara eksplisit memilih keluarga Cambria.

Logo khusus laporan (`../unpar-logo-report.png`) diambil dari logo utuh pada kop PDF referensi pengguna. Logo lama tetap dipertahankan untuk pemakaian lain.
